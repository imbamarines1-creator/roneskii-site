RONESKII GITHUB PAGES WEBSITE UPGRADE

FILES:
- index.html: storefront
- style.css: design, responsive layout
- script.js: search and category filtering
- products.js: editable product catalog

IMPORTANT: KEEP your existing privacy.html and about.html in your GitHub repository.
This upgrade does not replace or delete those files.

HOW TO INSTALL:
1. Open your repository: https://github.com/imbamarines1-creator/roneskii-site
2. Upload these FOUR website files (index.html, style.css, script.js, products.js) to the ROOT of main.
3. When GitHub asks, overwrite existing files of the same name by committing changes. The existing privacy.html should stay in place.
4. Wait a few minutes, then visit https://imbamarines1-creator.github.io/roneskii-site/
5. Refresh with Ctrl+Shift+R if you still see the old design.

HOW TO ADD REAL PRODUCTS:
Open products.js and replace sample objects. Use accurate product names, descriptions, category, and your OWN affiliate URL. Image should be your own/licensed image URL or a relative file such as images/frother.jpg. Upload image files to the matching images folder. Only use Amazon images as allowed by Amazon Associates terms. Keep the affiliate disclosure visible.

The product buttons remain disabled until a real URL is entered. No sample product is represented as a verified listing. This is a static site and needs no paid hosting.

The Pinterest link in the newsletter section points to Pinterest's homepage as a placeholder. Update it to your actual Pinterest profile URL in index.html.
