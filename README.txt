RONESKII FREE WEBSITE

1. Create a public GitHub repository named roneskii-site (or another name).
2. Upload index.html, about.html, privacy.html and style.css to the repository root.
3. In repository Settings > Pages, choose Deploy from a branch, main, / (root), and Save.
4. Once published, use the resulting HTTPS URL as the Company website or App link on Pinterest Developers.
5. Use that URL with /privacy.html appended as the privacy policy URL.
6. Check the website and policy for accuracy before submission. Add a reliable contact method, real product links and any required disclosures before public marketing.

IMPORTANT: This ZIP is a static website only. It does not provide a live Pinterest API backend, store secrets or publish Pins automatically. GitHub Pages publication and Pinterest approval are separate steps.
